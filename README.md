# Bedard_et_al_2026
Scripts and data for Bedard et al. 2026

Each folders contain the files and scripts to reproduce figures, as well as the associated statistical analyses. 

The scripts and information files related to the pooled competition assays performed in SC and different conditions were uploaded in the /Fitness_functions folder. The scripts and files used for processing raw sequencing data are in the /Read_processing folder and the sequencing data was deposited on SRA, BioProject PRJNA1508198 (kept private until the publication). Data can then be prepared for further analyses using the scripts and files in the /Data_preparation folder, the resulting dataframe for each gene/condition being deposited in the /Processed_data  folder.
